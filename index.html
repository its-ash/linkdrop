Questions

Does LinkDrop work with password-protected links?

Not yet — LinkDrop handles publicly accessible links. If a link needs a login or a token, it'll tell you it can't reach the file instead of failing silently.

What file types can it download?

Anything with a direct, downloadable file behind it — documents, images, video, audio, and archives. If the link points to a webpage instead of a file, LinkDrop lets you know rather than guessing.

Does it need permissions I should worry about?

Just storage access, to save files to your Downloads folder. LinkDrop doesn't read your other files, browsing history, or contacts.

Is it free?

Yes, no account and no paywall.
